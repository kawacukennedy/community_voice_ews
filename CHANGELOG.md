# Changelog

## [1.0.0] — 2026-07-30

### Added
- Initial release of Community Voice EWS
- SMS-based community reporting via Africa's Talking / Twilio
- NLP message classification (English + Swahili) for floods, droughts, pests, disease, fire, conflict, health
- Live interactive map with color-coded severity markers
- Two-way alert broadcasting to registered communities
- ICPAC official forecast integration (flood, drought, rainfall, multi-hazard)
- Dark mode, responsive design, offline-capable frontend
- REST API with automatic OpenAPI docs
- SQLite storage (zero-config), ready for PostgreSQL
- GitHub Actions CI/CD with linting, testing, and Render deployment
- `render.yaml` blueprint for one-click Render deployment
- Docker Compose for local development
